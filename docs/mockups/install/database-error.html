Нет соединения

Проверьте host, port, пароль и права пользователя. Пароль в сообщении не показывается.

Старая MySQL

MySQL 5.7 не поддерживается. Для старта требуется совместимая MySQL 8.0/8.4; 8.0 — только с согласованным EOL-исключением.

Нет FULLTEXT

Движок или права не позволяют выполнить FULLTEXT-проверку. Продолжение запрещено.
