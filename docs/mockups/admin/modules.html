Pages / дерево страниц — v1

PageTree и basic bindings входят в первую очередь. Вторая очередь: multisite, Landings / Services и сложные template rules. Здесь нет выбора сайта.

ZIP: Выключено по умолчанию; включается файлом на сервере

Только чтение · effective ZIP: OFF — файл отсутствует / false / недоступен / неверный формат
Путь задаёт env CMS_UPLOAD_POLICY_FILE: абсолютный private path вне web root.
Пример: /home/account/private/cms-upload-policy.json, не фиксированный путь.
Формат файла: {"module_zip_upload_enabled":true}. В этом состоянии значение: false; missing file, ошибка чтения/JSON или false → ZIP disabled.

Включает только оператор через серверный файл, не UI/DB/settings API. Даже true требует SystemAdmin executable-code capability, повторную auth + MFA/CSRF и environment readiness. При OFF — отказ на уровне приложения, без гарантии остановки передачи тела HTTP. Flag/context повторно проверяются перед extraction, исполняемым шагом и перед активацией; после начала DDL — безопасный checkpoint/maintenance, не принудительный SQL rollback. Папка incoming/READY не зависит от ZIP flag и проходит собственные проверки.
