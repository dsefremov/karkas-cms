Небезопасные пути в архиве

Найден ../config.php или файл вне папки модуля. Код не установлен и не выполнен. Пакет отклонён целиком.

Нет манифеста

manifest.json отсутствует или имеет неверную схему. Установка запрещена; запросите корректный пакет.

Несовместимая версия

Manifest требует Core >=2.0.0; текущая Core 1.8.0. Установка запрещена. Выберите совместимый пакет.

Обхода проверки / кнопки «всё равно установить» нет. Текущий сайт не изменён.

Понижение версии старым пакетом запрещено

Модуль Блог: установлено 1.4.2 → пакет 1.3.0 · отклонён.
Core: установлено 1.8.0 → пакет 1.7.0 · отклонён.
Одинаково для ZIP и папки; first install без current не является downgrade.

Rollback доступен только отдельным действием к единственному known previous slot после проверки совместимости, не загрузкой старого пакета.

Пример несовместимого candidate

Target cms/gallery 2.0.0 → требует Core >=2.0.0; установлено Core 1.8.0. Этот альтернативный candidate отклонён; выбранный штатный gallery 1.1.0 не меняется.
