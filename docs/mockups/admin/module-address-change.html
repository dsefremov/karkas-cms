301 обязательны для освобождённых опубликованных адресов.
Только GET/HEAD; POST, формы, auth и API не переигрываются. Query переносится по allowlist, без секретов.

/blog всегда принадлежит модулю Блог.
Страница живёт на своём пути в дереве: «Журнал» — /journal, этот адрес модулю не отдаётся. При смене основного адреса все опубликованные маршруты модуля, включая root /blog, получают 301 (GET/HEAD). Исключения «страница оставляет /blog» нет.

План хранит stable object IDs и route names. Источники зарезервированы до утверждённого expiry/removal impact; циклы/цепочки проверены. Проверяется единый route plan и default layout для нового префикса. Сложные правила шаблонов здесь не настраиваются.
