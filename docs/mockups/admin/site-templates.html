Условия v1

Точное: весь normalized site-relative path, без host, query и fragment.

Префикс по сегментам: /blog и /blog/post, но не /blogger.

*: ровно один непустой сегмент. /lendings/* → /lendings/sale; не корень и не /lendings/sale/extra.

**: только отдельным последним сегментом, ноль и больше сегментов. /lendings/** включает корень и любое допустимое продолжение.

Нет foo*, ?, скобок, альтернатив или произвольных выражений. Универсальные /** и prefix / не обычные правила: используйте default.

Стартовые app caps: ≤100 правил/site, маска ≤256 UTF-8 bytes / 32 segments / 8 wildcard tokens. Совпадение — bounded segment matcher.

Ошибки сохранения

Пример: «Порядок 20 уже занят. Укажите уникальное число».

Если rules generation изменилась: «План устарел, обновите preview». Drag reorder — единый atomic renumber с expected version, не last-write-wins.

Правила меняют layout, не URL-владение и не ACL. Конфликт route ownership не разрешается первым совпадением. Условия не переписываются молча при изменении mount/page.
