Host и longest-segment-prefix

Только verified host с ready binding. /partners не равно /partners-old. Отключённая или pending область /partners сохраняет reservation и возвращает deny/404, а не падает в корневой сайт.

Unknown/unverified host отклоняется. «Основной» — удобство администрирования, не fallback неизвестного Host.

Выбор шаблона

После выбора сайта и route generation правила проверяются по уникальному порядку сверху вниз. Первое совпадение побеждает, fallback всегда последний.

Шаблоны
Сайт: draft / active / disabled / archived. Домен: pending verification → verified → DNS/TLS pending → ready, ошибки отдельно. Save не создаёт DNS/SSL; alias только verified и в своём site scope.
